# PROXY ZERO Stage 1 플레이 안내서

이 문서는 현재 저장소의 조작키와 캐릭터 기술을 기준으로 작성한 초보자용 안내서입니다. 배포가 완료되었다는 뜻은 아니며, 로컬에서 실행하고 플레이하는 방법만 설명합니다.

## 1. 설치 및 실행

명령 프롬프트 또는 PowerShell에서 저장소 루트로 이동한 뒤 실행합니다.

### 개발 서버

```powershell
npm install
npm run dev
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:5173
```

터미널에 다른 포트가 표시되면 터미널에 표시된 주소를 사용하세요.

### 프로덕션 빌드 미리보기

개발 서버를 종료한 뒤 다음 순서로 실행합니다.

```powershell
npm run build
npm run preview
```

기본 미리보기 주소는 다음과 같습니다.

```text
http://localhost:4173
```

`npm run build`는 실제 배포를 수행하지 않고, 로컬에서 배포용 빌드가 만들어지는지만 확인합니다.

## 2. 게임 시작 순서

1. **Title** 화면에서 `Enter`를 누릅니다.
2. **Character Select** 화면에서 `ArrowLeft` 또는 `ArrowRight`로 캐릭터를 고릅니다.
3. 원하는 캐릭터가 선택된 상태에서 `Enter`를 누릅니다.
4. **Combat** 화면이 나타나면 전투가 시작된 것입니다.

처음에는 캔버스를 한 번 클릭해 게임에 키보드 입력 포커스를 주세요.

## 3. 기본 조작

| 동작 | 키 | 설명 |
| --- | --- | --- |
| 이동 | `W` `A` `S` `D` | 상하좌우로 이동합니다. |
| 달리기 | `D` 두 번 누른 뒤 두 번째 `D` 유지 | 첫 번째 `D`를 눌렀다 뗀 뒤, 짧은 시간 안에 두 번째 `D`를 누르고 계속 누릅니다. |
| 점프 | `Space` | 캐릭터가 공중으로 뜹니다. |
| 왼손 공격 | `J` | 왼손 공격입니다. |
| 오른손 공격 | `K` | 오른손 공격입니다. |
| 왼발 공격 | `L` | 왼발 공격입니다. |
| 오른발 공격 | `;` | 세미콜론 키에 해당하는 오른발 공격입니다. |
| 아이템 선택 | `Q` | 사용할 아이템을 바꿉니다. |
| 줍기·사용 | `E` | 가까운 아이템을 줍거나 선택한 아이템을 사용합니다. |

### 공중 공격

`Space`로 점프한 뒤 공중에 있는 동안 `J`, `K`, `L`, `;` 중 하나를 누르면 공중 공격이 나갑니다. 캐릭터마다 공중 공격 동작은 다릅니다.

## 4. 캐릭터별 기술 입력표

입력은 표의 **왼쪽에서 오른쪽 순서**로 빠르게 누릅니다. 화면 아래 HUD에도 같은 기술 안내가 표시됩니다.

| 캐릭터 | 기술 입력 | HUD 기술명 |
| --- | --- | --- |
| HAN | `K → J` | CROSS |
| HAN | `L → ; → K` | RISING |
| HAN | `100% K → J → ; → L` | TEMPEST |
| MINA | `K → ;` | FLASH |
| MINA | `L → K → L` | SKY NEEDLE |
| MINA | `100% J → K → L → ;` | PRISM |
| JIN | `J → K` | ANCHOR |
| JIN | `; → L → K` | FAULT LINE |
| JIN | `100% ; → L → J → K` | ZERO |

`100%`가 붙은 기술은 HUD에 표시되는 게이지가 가득 찼을 때 사용할 수 있습니다.

## 5. 입력이 잘 되지 않을 때

아래 순서대로 하나씩 확인하세요.

1. 브라우저 페이지를 **새로고침**합니다.
2. 게임 화면의 **캔버스를 한 번 클릭**한 뒤 다시 키를 누릅니다.
3. 키보드 입력이 **한/영 전환 상태가 아닌 영문 입력 상태**인지 확인합니다.
4. 오른발 공격은 `;` 키인지 확인합니다. 키보드 배열에 따라 세미콜론 키의 위치가 다를 수 있습니다.
5. 개발 서버 또는 미리보기 서버가 실행 중인지 터미널을 확인하고, 터미널에 표시된 브라우저 URL을 다시 엽니다.
